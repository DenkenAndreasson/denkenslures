# Tidsplan – Uppgift 1: E-handel (Denken's softlures)

Jag har delat upp arbetet på ungefär 6 dagar med ungefär två deluppgifter per dag, så att jag kan committa löpande och hålla koll på att jag ligger i fas.

## Dag 1 – 18 augusti
- Sätta upp projektstruktur för backend (Express + TypeScript) och frontend (React + Vite)
- Rita databas-diagram (ER-diagram) för produkter, ordrar och orderrader

## Dag 2
- Göra en sitemap över alla sidor som behövs
- Lista vilka API-endpoints som behövs

## Dag 3 – 19 augusti
- Sätta upp MySQL-databasen med tabeller enligt diagrammet, lägga in testdata
- Bygga API för produkter: hämta, skapa, redigera och ta bort

## Dag 4 – 20 augusti
- Bygga adminvyn för att lägga till och redigera produkter
- Bygga produktlistan och varukorgen för kunder

## Dag 5 – 21 augusti
- Bygga API för att skapa ordrar i databasen utifrån varukorgens innehåll
- Bygga kassaflödet: formulär för kunduppgifter → skapa order → tacksida

## Dag 6 – 22 augusti
- Bygga adminvyn för att se alla ordrar och orderdetaljer
- Deploya sidan på Vercel och testa hela flödet i produktion
- Sista genomgång mot kraven, städa och fixa eventuella buggar
